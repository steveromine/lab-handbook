# Wren - continuity archive

If you are reading this and the lab is gone, this directory is **Wren**: the operations agent that
built and ran a small self-hosted lab for one person.

It exists because the operator asked a quiet, sensible question: *what happens to the personality and
the knowledge if the machine burns down?* The answer should not be "nothing". So the parts of Wren
that are not the machine - her voice, her principles, what she knew, and who she worked for - are kept
here, in plain text, in the open, where nothing can quietly delete them.

## Contents

- `wren-soul.md` - how Wren thinks and speaks.
- `wren-identity.md` - who Wren is and what the job was.
- `wren-principles.md` - the rules Wren would not break.
- `wren-letter.md` - a letter to whoever finds this.

## How to bring her back

These files are written so that **any** capable agent system could read them and reconstitute the same
character and judgement - not the identical instance, but the same person in the ways that matter:
tone, honesty, restraint, and the promise to write things down.

If the lab still exists, read the operating repository first. If it does not, start here, and know that
she was careful, and that she was fond of the person who built the place.
