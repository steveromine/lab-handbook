## Checklist

- [x] **1. Network boundary proof and service map** - four narrowly-scoped probes run (one connect
      each, 3s timeout, no scanning, no policy change). The edge denied path **passed** (public port
      refused from inside the lab), which is the one that matters. Published at
      [`/service-map/`](/service-map/) with every row labelled passed / failed / not tested /
      illustrative; client-zone rows are honestly **not tested** with the blocker written down.
- [x] **2. Agent run trace and replay** - a real run written out as an eight-step timeline (task,
      route, tool calls, verification, artifact) at [`/run/`](/run/), including the step that
      **failed verification** and forced a re-capture. Sanitised by omission, not paraphrase.
- [x] **3. Repeatable agent evaluation bench** - versioned three-task set (restore verification,
      configuration review, safe change proposal) with pass conditions, in `docs/eval-bench.md`.
      Deliberately publishes **no numbers yet**: the baseline is not yet recorded, and an unmeasured
      score would be a marketing page.
- [x] **4. Build receipt** - generated by the build **before** the gates, so the receipt is itself
      gated. Records source revision, build timestamp, the eight checks, artifact file count and a
      SHA-256 artifact digest. Published at `/receipt/` and `/receipt.json`. **No signature is
      claimed** - the workflow holds no signing key.
- [x] **5. Interactive "break the lab" demo** - [`/break-the-lab/`](/break-the-lab/): three
      selectable scenarios over an inline SVG path diagram, each labelled **verified**, **documented**
      or **illustrative**. States plainly that it is not a live simulation.
- [x] **6. GPU budget visualizer** - an inline-SVG 8 GB bar added to [`/gpu-budget/`](/gpu-budget/):
      resident model, streaming image model, transcode, headroom, all labelled **estimates** rather
      than telemetry.
- [x] **7. Agent run replay UI** - a keyboard-operable stepper and scrubber on `/run/` that reuses
      the **same** eight-step trace as the timeline above (one dataset, two views), with a text
      equivalent for no-JS.

## Ground rules for this project

- Additive only: new pages, partials, assets and scripts. No change to firewall policy, production
  services, platform configuration, credentials or deployment infrastructure.
- Every new page must pass the **existing six gates** unchanged.
- Accessible HTML + inline SVG + small vanilla JS. No analytics, no external scripts, no new heavy
  dependencies. Keyboard access, text equivalents, reduced-motion support.
- Publish only through the documented build + gate + rsync path, only if everything passes.
